Nuxt-first package

Phone input designed for Nuxt.

nuxt-phone-number is a module-first phone input for Nuxt 3 and Nuxt 4 with auto-imported UPhoneInput, usePhone(), global configuration through nuxt.config.ts and UI props aligned with a Nuxt UI style of development.

Auto-import SSR-ready usePhone() Nuxt config

✨Features

The module is built around Nuxt ergonomics rather than a plain Vue component wrapper.

🧩
Auto-registered component
Use <UPhoneInput /> anywhere after adding the module, without manual imports.
🔌
Composable injection
Access formatting, validation and parsing helpers with usePhone().
⚙️
Global defaults
Configure default country, preferred countries and format globally in nuxt.config.ts.
🎨
Nuxt UI style API
Supports props like variant, size and rounded for app-wide consistency.

📦Installation

Install the module and the phone formatting dependency. 

npm install nuxt-phone-number libphonenumber-js

🧪Usage

The default API is intentionally simple and Nuxt-oriented. 

<script setup lang="ts">
const phone = ref("");
</script>

<template>
  <UPhoneInput
    v-model="phone"
    variant="outline"
    rounded="lg"
  />
</template>

🛠Nuxt Config

Set app-level defaults once, then reuse them everywhere. 

export default defineNuxtConfig({
  modules: ["nuxt-phone-number"],

  phoneInput: {
    defaultCountry: "SN",
    preferredCountries: ["SN", "FR"],
    format: "international",
    ui: {
      variant: "outline",
      size: "md",
      rounded: "lg"
    }
  }
})

🧠usePhone

Injected helpers are available through a single composable. 

<script setup lang="ts">
const { formatPhone, validatePhone, parsePhone, defaults } = usePhone();

const formatted = formatPhone("+221771234567");
const isValid = validatePhone("+221771234567");
const parsed = parsePhone("+221771234567");
</script>

🧾Component API

Core props already available in the current scaffold.

Prop Type Default Description
modelValue string "" Phone value bound with v-model.
countryCode string undefined Selected country via v-model:country-code.
variant "outline" | "soft" | "ghost" "outline" Visual style of the field shell.
size "sm" | "md" | "lg" "md" Control density and spacing.
rounded "sm" | "md" | "lg" | "xl" | "full" "lg" Border radius preset.
preferredCountries string[] [] Countries shown first in the dropdown.
format "national" | "international" | "e164" "international" Output mode used by the component and helpers.
error string | boolean undefined Forces an error state or custom validation message.

🚀Nuxt Vision

The current scaffold is the foundation. The roadmap can push it into a stronger Nuxt-specific package.

SSR & hydration

Keep browser-only behavior isolated and make all locale defaults safe during server rendering.

Afrique-first UX

Strong defaults around Senegal and broader African carrier and numbering patterns can become a product differentiator.

Nuxt UI alignment

Extend the visual API to feel native in projects already using UInput-style conventions.

App helpers

Expand usePhone() with smarter parsing, localized messaging and optional WhatsApp-oriented utilities.
